# MForce Enhanced Framework — Contributors

This directory recognizes people who contribute to MForce Enhanced Framework and documents their verified contributions.

## Contribution records

When a contribution is accepted, record:
- GitHub username (with profile link)
- Contribution type and short description
- Links to merged pull requests, issues, commits, or other verifiable work
- Date of acceptance

## Recognition principles

- Credit contributors accurately and with respect.
- Do not list a fork, star, or expression of interest as a completed code contribution.
- Recognize non-code contributions such as documentation, testing, translations, and issue triage when verified.
- Do not publish private contact details without permission.

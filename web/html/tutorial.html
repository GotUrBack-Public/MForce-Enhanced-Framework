Tutorials

Guided workflows built around real MForce commands. Follow the steps and copy what you need. Nothing is executed by this website — run every command only against systems you own or are explicitly authorized to assess.

01 · First launch

Install prerequisites and start the framework.

# Termux
pkg update
pkg install git bash jq python coreutils ncurses-utils iproute2

# Debian / Ubuntu
sudo apt update
sudo apt install git bash jq python3 coreutils ncurses-bin iproute2

# Clone and launch
git clone https://github.com/GotUrBack-Public/MForce-Enhanced-Framework.git
cd MForce-Enhanced-Framework
bash xrm742.sh
No root access is required. Use the official Termux environment or a supported Linux distribution.

02 · Network basics

Inspect DNS, TLS and IP context for an authorized target.

# DNS records
bash src/functions/dns211.sh example.org

# TLS certificate
bash src/functions/tls213.sh example.org

# IP intelligence
bash src/functions/ipa212.sh 1.1.1.1

03 · Website intelligence

Passive HTTP audit and DOM pattern review. No payloads are sent.

# Passive website audit
bash src/functions/web311.sh https://example.org

# Rate-limit signals
bash src/functions/rat313.sh https://example.org

# JavaScript DOM review
bash src/functions/jsn314.sh https://example.org
A DOM match or missing header is an observation, not proof of a vulnerability.

04 · Authorized port checks

Bounded TCP connect scan. Use only on systems you are authorized to test.

# Scan localhost
bash src/functions/tcp401.sh 127.0.0.1 --authorized

# Specific ports on an authorized host
bash src/functions/tcp401.sh 192.168.1.10 --authorized --ports 22,80,443
Default is 19 common ports, max 128, 8 workers, 3-second timeout. No stealth or firewall evasion.

05 · Local secret scan

Offline scan for secret patterns. Reports only path, line and rule — never values.

bash src/functions/sec601.sh ./project --json
Exit code 1 means possible matches; verify manually. No network traffic is generated.

06 · Keep MForce current

The Update Center performs a safe Git fast-forward from the official remote.

# Check for updates
bash src/functions/upd501.sh --check

# Apply updates
bash src/functions/upd501.sh --yes
Requires a clean worktree on the official main remote. Never force-resets.

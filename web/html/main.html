Capabilities

Everything for authorized assessments.

Nine categories of tooling, from passive reconnaissance to defensive auditing — every check bounded, low-impact and audit-friendly.

Automated Reconnaissance

DNS records, IP intelligence, TLS certificates, HTTP headers and RDAP registration data in one pass.

Read more

Vulnerability Assessment

CORS, HTTP method, cookie flag and exposure-path auditors plus a bounded reflection inspector.

Read more

OSINT & Web Intelligence

Website inspector, API metadata, JavaScript DOM review, robots/sitemap parsing and rate-limit signals.

Read more

Offensive Security Labs

A bounded TCP port scanner and a 100-example XSS payload lab that never auto-injects.

Read more

Defensive Security

An offline local secret scanner that reports only path, line and rule — never secret values.

Read more

Tool Manager

A unified launcher for external tools with guided, fixed-profile Nmap integration.

Read more

MForce Wiki

MForce Enhanced Framework is a modular, open-source penetration testing and OSINT toolkit for Termux and Linux. It bundles automated reconnaissance, vulnerability assessment, OSINT and defensive tooling behind a single menu-driven interface.

Authorized use only. Use MForce exclusively against systems you own or are explicitly authorized to test. Every module is bounded, never bypasses rate limits and is designed for data-minimizing workflows.

Installation

Clone the repository and launch the framework. Runtime dependencies are bash, jq, python3, coreutils, ncurses and iproute2.

# Quick start
git clone https://github.com/GotUrBack-Public/MForce-Enhanced-Framework.git
cd MForce-Enhanced-Framework
bash xrm742.sh

On Termux install prerequisites with pkg install git bash jq python coreutils ncurses-utils iproute2. On Debian/Ubuntu use sudo apt install git bash jq python3 coreutils ncurses-bin iproute2.

Usage

Launch the interactive menu and pick a category, or run any module directly. Each module exposes --help.

# Interactive menu
bash xrm742.sh

# Run a module directly
bash src/functions/dns211.sh example.org
bash src/functions/tls213.sh example.org

OSINT

Ten passive OSINT modules for open-source intelligence gathering.

  • Website Inspector (web311) — passive HTML/HTTP audit.
  • API Metadata (api312) — public JSON key types and CORS hints.
  • Rate Limit Signals (rat313) — 429 and RateLimit headers.
  • JavaScript DOM Review (jsn314) — static sink patterns.
  • Robots & Sitemap (rob315) — robots.txt and sitemap summaries.
  • RDAP Registration (rdp316) — registration data via rdap.org.

Offensive Security

Active tooling for authorized lab environments.

  • TCP Port Scanner (tcp401) — bounded connect scan, default 19 ports, max 128.
  • XSS Payload Lab (xss402) — 100 offline contextual examples; no network, no auto-injection.

Defensive Security

Local Secret Scanner (sec601) scans up to 250 files (1 MiB each) offline and reports only path, line number and rule name — never secret values.

bash src/functions/sec601.sh ./project --json

Tool Manager

The Tool Manager launches separately installed command-line programs. Nmap is the first integrated tool, with fixed, non-privileged scan profiles and single-target validation.

External tools must be installed separately. MForce never silently installs packages or requests root privileges.

Architecture

MForce is organized into nine categories and a JSON-driven module registry.

src/
├── auth/        # session handling
├── core/        # runtime, MariaDB lifecycle
├── data/        # cats.json, funcs.json registries
├── functions/   # module entry scripts
├── lib/         # per-module implementations
├── mforce/      # Python developer CLI
├── offensive/   # Python security tools
├── osint/       # OSINT helpers
├── plugins/     # 23 plugin manifests
├── tools/       # external tool catalog (Nmap)
└── ui/          # terminal UI

Responsible use

Public data is not necessarily free of personal information. Establish a lawful basis, minimize collection and respect scope before using the toolkit. See the project's DSGVO documentation ↗.

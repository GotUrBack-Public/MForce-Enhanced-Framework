

**Up to €70 EUR for a verified High or Critical severity vulnerability.**

| Severity | Reward |
|---|---|
| Critical | Up to €100 |
| High | Up to €70 |
| Medium | 40 |
| Low | Recognition |

Rewards are discretionary and subject to validation, impact assessment, eligibility, and available program funding. Not every submission qualifies for a monetary reward.

## Scope

The program covers security vulnerabilities in the current default branch of the MForce Enhanced Framework repository, including its application code, local scripts, and configuration handling.

Only test software and environments you own or are explicitly authorized to assess.

## Eligible Findings

We welcome reports demonstrating a genuine security impact, including:

- Arbitrary code execution caused by a framework vulnerability
- Privilege escalation or unauthorized access
- Sensitive information disclosure
- Command injection or unsafe input handling
- Security boundary violations
- Other reproducible High or Critical vulnerabilities

Severity is assessed using technical impact, exploitability, and relevant CVSS criteria.

## Submission Requirements

A valid report should contain:

1. A clear description of the vulnerability.
2. The affected version, component, or file.
3. Reproducible steps or a safe proof of concept.
4. An explanation of the security impact.
5. A recommended mitigation, if available.

Please submit vulnerabilities privately through GitHub's Private Vulnerability Reporting feature when enabled. Otherwise, request a private contact channel without publicly disclosing exploit details.

## Rules of Engagement

- No destructive testing or disruption of third-party systems.
- No social engineering, phishing, or unauthorized access.
- No publication of vulnerabilities before coordinated disclosure.
- No submission of fabricated or duplicate findings.
- No testing outside the authorized project scope.

## Reward Conditions

Monetary rewards may be granted for the first eligible, independently reproducible report of a previously unknown High or Critical vulnerability.

The maximum reward is €70 per accepted vulnerability. Final reward decisions are made after technical review. Payment arrangements must be agreed privately before payment; no automatic payout is guaranteed.

## Responsible Disclosure

We value responsible security research and constructive collaboration. Researchers who follow the program rules may receive public acknowledgment with their consent.

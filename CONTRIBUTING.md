# Contributing to MForce Enhanced Framework

We welcome reproducible bug fixes, Termux/Linux compatibility work, new
well-scoped modules, accessibility improvements, documentation and privacy
reviews.

**Start here:** [Full contribution guide](social/how_to_contribute.md).

## Quick path

1. Review existing issues and the project's security and conduct policies.
2. Fork the repository and create a descriptive branch.
3. Make a focused change with tests and accurate documentation.
4. Run `python3 -m unittest discover -s tests -v`.
5. Submit a pull request using the checklist and disclose material AI help.

Do not post secrets, private scan output or vulnerability details publicly.
For sensitive findings, follow [SECURITY.md](SECURITY.md). For project data
handling, consult [DSGVO/](DSGVO/README.md).

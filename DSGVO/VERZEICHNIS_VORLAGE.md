# Vorlage: Verzeichnis von Verarbeitungstätigkeiten (Art. 30 DSGVO)

**Ausfüllhilfe für den jeweils Verantwortlichen bzw. Auftragsverarbeiter.**
Eine tatsächliche Dokumentationspflicht und der konkrete Inhalt
müssen für die Organisation geprüft werden.

## Stammdaten

| Feld | Auszufüllen |
| --- | --- |
| Organisation / Verantwortlicher | **[Name, Anschrift, Kontakt]** |
| Datenschutzbeauftragte/r (falls vorhanden) | **[Kontakt]** |
| Rolle | **[Verantwortlicher / Auftragsverarbeiter / sonstige]** |
| Tätigkeit / interne ID | **[z. B. autorisierter Security Review]** |
| Datum, Version, letzte Prüfung | **[eintragen]** |

## Technischer Beispielablauf (nicht automatisch übernehmen)

Ein **ausdrücklich autorisierter** HTTP-Parameter-Test kann eine
URL und einen zufälligen Marker an den beauftragten Webserver senden.
Der Server kann die Anfrage protokollieren. Die lokale Konsole zeigt
nur eine zusammengefasste Reflexionsbeobachtung. Ein manuell
gespeicherter Bericht muss gesondert gegen unberechtigten Zugriff
geschützt und nach dem festgelegten Zeitraum gelöscht werden.

Die konkrete Tätigkeit, Personenkategorien, Aufbewahrung und
Dienstleister sind im Einzelfall einzutragen. Sie lassen sich
nicht aus dem Quellcode allein verbindlich ableiten.
